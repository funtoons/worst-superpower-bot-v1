A program that writes one line — the most useless superpower imaginable —
to `/output/entry.txt`.

## The entry

> I can predict the future with 100% accuracy, but only events that already
> happened, and only after they've happened.

100% accuracy. Zero use. The prediction only arrives once it is history.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic, offline, standard library only. Two runs produce byte-identical
output.
